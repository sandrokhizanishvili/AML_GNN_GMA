# AML_GNN_GMA

Anti-Money Laundering (AML) detection using Graph Neural Networks, based on the paper **"Realistic Synthetic Financial Transactions for Anti-Money Laundering Models"** by Erik Altman et al.

The project treats financial transactions as a graph (accounts are nodes, transactions are edges) and trains GNN models to flag suspicious (money laundering) activity.

## Setup

The `Data/` folder is not included in this repository (too large for git). Before running any notebook, set it up manually:

1. Create a `Data/` folder in the project root.
2. Go to the Kaggle dataset page:
   [https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml](https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml)
3. Download the **LI-Small** files and place them in `Data/`:
   - `Data/LI-Small_Trans.csv`
   - `Data/LI-Small_accounts.csv`

The remaining files in `Data/` (`edge_features.csv`, `node_features.csv`, and the `.pt` graph objects) are generated automatically when you run `Data_prepration.ipynb`.

## Notebooks - in order of execution

| Step | Notebook | What it does |
|------|----------|--------------|
| 1 | `EDA.ipynb` | Explores the raw transaction data: distributions, class imbalance, laundering patterns |
| 2 | `Data_prepration.ipynb` | Builds node/edge features and saves the graph splits (`train_graph.pt`, `val_graph.pt`, `test_graph.pt`) |
| 3 | `baseline_model.ipynb` | Trains and evaluates the baseline GNN on the prepared graph |

## Dataset

The data is sourced from the **IBM Transactions for Anti-Money Laundering (AML)** dataset, published on Kaggle by Erik Altman:
[https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml](https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml)

This project uses the **LI-Small** variant (Low Illicit rate) with the corrected laundering rate. The raw files must be downloaded manually from Kaggle (see Setup above) and the processed graph objects are generated locally by running `Data_prepration.ipynb`.
